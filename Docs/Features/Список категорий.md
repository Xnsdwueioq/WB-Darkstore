# Список категорий
#### Кратко
Работаем в `origin/feature/categories`, создаем каждый свою ветку например `feature/task/categories-network`.
Делаем экран с категориями
```
CatalogView(4) + UISystem(2) ->
CatalogModel(3) ->
CatalogService(1) + Protocol(1)
```
#### Контракты
Можем работать параллельно
```Swift
protocol CatalogServiceProtocol {
    func getCategories() async throws -> [Category]
}

struct Category {
    let id: String
    let name: String
    let imageURL: URL?
}

CategoryCard(category: Category)
```

#### Задачи
**1 роль**
1. Ставлю `СompositionRoot` в корне приложения для DI 
2. Предоставляет `CatalogService` через `CatalogServiceProtocol`: `getCategories()` возвращает `[Category]`.
3. Контракт сервиса: [CatalogService](../CatalogService.md).

**2 роль**
1. Async Image (можно делать сразу кэш через Nuke, могу скинуть как я делал)
2. Компонент-карточка категории (можем выбрать у кого самая красивая :) )
3. Наполнение дизайн системы шрифтами, базовыми отсупами (допустим отступ по бокам, который во всем приложении появляется)
4. Возможно формирует конфигурацию UI для `View`. Пример как я делал
```Swift
struct CategoriesView: View {
	...
	private enum Configuration {
		static let horizontalSpacing: CGFloat = 12
	}
	
	var body: some View {
		...
	}
}
```

**3 роль**
1. enum `ViewState`: будет отображать стейт вьюшки во всех частях приложения
2. `CatalogModel`: принимает `CatalogService`; хранит `[Category]` и `[Product]`, текущий `LoadState` для категорий и отдельно для продуктов (`categoriesState`, `productsState`); методы обращаются к сервису, обрабатывает ошибки и возвращает их интерпретацию для юзера во view; метод для перезагрузки (типо `retry`), который будет вызывать вью в случае алерта
3. Мок/фейк вариации для тестирования

**4 роль**
1. Подготавливает `TabView` (каталог, избранное, корзина, поиск)
2. Собирает `View` в плане структуры.
3. Делает обработку сообщений об ошибок + кнопка для перезагрузки
4. Возможно берет задачи 2 роли
